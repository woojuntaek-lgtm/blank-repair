# 빈칸 수선소

1%씩 빈 열 100개, 빈칸 있는 행을 지우면 37%만 남는다 — 데이터 전처리를 손으로 체험하는 앱입니다. 행 삭제로 사라지는 데이터, 개체·참조·도메인 무결성 찾기, 결측의 세 유형(완전 무작위·무작위·비무작위)과 소득 조사 실험, 직전 값·직후 값·선형 보간·평균 채우기, 평균 채우기가 만드는 인공 봉우리, 결측률에 따른 방법 고르기, 레이블·원 핫 인코딩, 자료형 메모리 다이어트까지 담았습니다. 빅데이터 03 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다. 모든 데이터는 가상 예시입니다.

## 구성
- ① 지우기: 열 개수·결측률 슬라이더로 남는 행 비율과 40행 표본 그림, 퀴즈 ①
- ② 왜 비었나: 무결성 오류 찾기 게임, 결측 세 유형, 퀴즈 ②, 소득 조사 비무작위 결측 실험
- ③ 채우기: 센서 시계열 채우기 4가지, 평균 채우기 히스토그램과 표준편차 감소, 결측률별 방법 안내와 분야 맥락
- ④ 정리: 레이블 vs 원 핫 인코딩, 100만 행 메모리 다이어트, to_numeric(errors="coerce"), 세 줄 정리, 생각해 볼 질문
